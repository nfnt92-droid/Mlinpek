Put original photographs here, named after the slot id in src/content/photos.ts
(e.g. `mill-hall.jpg`, `bake-kruh.tif`), then run `npm run photos`.

Optional `credits.json`:
{ "mill-hall": { "credit": "Foto: Ime Prezime / Unsplash", "temporary": true } }

Originals are git-ignored; only the optimised renditions in public/photos are committed.
