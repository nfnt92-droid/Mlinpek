## Zamjena vlastitim fotografijama

Spremite vlastitu fotografiju kao `photo-sources/<slot>.jpg`, izbrišite zapis te pozicije iz `photo-sources/credits.json` (ili postavite `"temporary": false`), pokrenite `npm run photos` i `npm run build`. Oznaka *Privremena fotografija* nestaje sama. Opis kadra koji treba snimiti za svaku poziciju nalazi se u `PHOTOS.md`.
